# DMart Retail Sales & Profit Dashboard

Interactive Excel dashboard analysing a full year of retail data (Jan–Dec 2025) to track sales, profit and category performance.

## Dashboard Preview

[![Dashboard Overview](dashboard-1.png)](https://github.com/Prachi217/Dmart-sales-dashboard/commit/2e80246b6f2ba2d509e96cbc5012bec55de6fb21)

## Dataset

- 40,589 transaction lines across 18,935 bills
- 105 SKUs across 5 categories
- 3 payment modes
- Linked tables: transactions, SKU, sales and calendar

## Key KPIs

- Net sales: ₹1.56 crore
- Net profit
- Average bill value
- Bill count

## Key Insights

- Staples is the most profitable category (₹11.6 lakh)
- Personal Care is the least profitable category (₹4.1 lakh)

## Tools Used

Microsoft Excel · Pivot Tables · Slicers · Data Modelling

## How to Use

Download `dmart-sales-dashboard.xlsx` and open it in Excel. Use the slicers to filter by category, month and payment mode.
